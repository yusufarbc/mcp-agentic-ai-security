- `MCP.webp`: MCP architecture/ecosystem visual.
- `client-server-model.webp`: Client-server architecture diagram.
- `model.webp`: Protocol model diagram.
- `post.webp`: Social/blog post visual.

All images are stored as WebP to keep the repository lightweight.
